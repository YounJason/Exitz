# PC
### 1. 메인 페이지에서 '마이 쿠팡'을 클릭하세요.
마이 쿠팡은 페이지 우측 상단에 있습니다.
### 2. 좌측 하단 'MY 정보' 카테고리의 ['회원 탈퇴'](https://login.coupang.com/login/secession.pang)를 클릭하세요.
### 3. 회원 탈퇴 시 유의사항에 동의하고 비밀번호를 입력한 뒤 '다음' 버튼을 누르세요.
### 4. 이용 내역을 확인한 뒤 탈퇴 절차에 동의하고 '탈퇴하기' 버튼을 누르세요.
쿠팡 와우 멤버십에 가입되어 있으신가요? 탈퇴하기 전 멤버십을 해지하세요.
